# Local AI Assistant

An offline-first Electron, React, and Express foundation for experimenting with adaptive retrieval, memory, tools, and Ollama. Advanced storage, embeddings, and reranking are intentionally replaceable placeholders.

## Quick start
1. Copy `.env.example` to `.env`.
2. Run `npm install`.
3. Run `npm run dev` (the server works without Ollama using a clear fallback response).

See `docs/development.md` and `docs/architecture.md`.
